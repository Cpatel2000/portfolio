03. Projects

Brain-Computer Interface

Emotion recognition from EEG brain signals using CNN and LSTM deep learning models. Used Fast Fourier Transform for feature extraction. LSTM gave the best accuracy across 75-25 and 80-20 train-test splits.

  • Python
  • CNN
  • LSTM
  • EEG
  • FFT

Grill Thermometer

Embedded system on the G070 board that reads a meat probe thermocouple (freezing to 150+C), uses a PCB thermistor for cold junction compensation, stores calibration in EEPROM, and has a UI for selecting target temps by meat type and doneness with an audible alert.

  • C
  • Assembly
  • G070
  • EEPROM
  • Thermocouple

Real-time Age, Gender & Emotion Detection

Computer vision project that detects faces using Haar Cascades and classifies age, gender, and emotion in real time. Uses Caffe models for age/gender prediction and a custom trained model for emotion classification.

  • Python
  • OpenCV
  • Caffe
  • Haar Cascades

GPS Embedded System

ARM Cortex microcontroller with multiple data streams over RS485, sending data through fiber optic links to remote display modules. PC commands control LEDs on remote modules and report back GPS coordinates.

  • C
  • ARM Cortex
  • RS485
  • Fiber Optics
  • GPS

8x8 Internet Switch Verification

UVM testbench for an 8x8 internet switch with full functional coverage. Ran SMOKE, 1-PORT, 4-PORT, and CONCURRENT tests across all source/destination port combinations. Compiled with Synopsys VCS.

  • SystemVerilog
  • UVM
  • Synopsys VCS
  • Makefile

RAG Teaching Assistant

Chatbot for university students that uses Retrieval Augmented Generation. Ingested educational resources into Elastic Search with optimized vector embeddings for context-aware answers to student questions.
